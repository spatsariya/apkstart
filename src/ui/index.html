Install Android to virtual disk

The virtual machine is open. Follow these six steps once; future launches will use the virtual disk.

  1. Boot menu : Use ↓ to choose Installation - Install Android-x86 to harddisk and press Enter
  2. Choose Partition : Select Create/Modify partitions; if prompted to use GPT, select No
  3. cfdisk partitioning：New → Primary → press Enter for the default size → Bootable → Write → type yes → Quit
  4. Format : Select vda1 → when prompted, choose ext4 → Yes
  5. Bootloader and system：Install GRUB select Yes；Install /system as read-write select Yes
  6. Finish: At 100%, click 'I have finished installing'. ApkStart will restart and take control.

If adb is disconnected, press Ctrl+Alt+F1 in the virtual machine to open a terminal and run setprop service.adb.tcp.port 5555、stop adbd、start adbd， Then press Ctrl+Alt+F7 to return to the graphical interface.

Application windows
Press F11 or right-click the tray icon to switch modes. Fullscreen preserves the aspect ratio without restarting the app.
When enabled, apps open in fullscreen automatically. It works best with landscape orientation. because the landscape panel fills widescreen displays more naturally.
Android orientation depends on the virtual device's physical panel orientation. If the app's orientation does not match, Android may letterbox it. Resizing the window cannot fix this. Follow app reads the APK orientation and switches the virtual panel to match. For apps such as Hongguo and Modu, content can fill the display. Android restarts only when an orientation switch is needed. Apps with the same orientation launch without another restart.
Inside Android, auto-rotation is enabled by default; the physical panel and screen orientation are still controlled by the above orientation policy. The setting matters mainly to apps that read the auto-rotation flag.
At 720 pixels wide and 190 dpi, the logical width is 606 dp, above Android's 600 dp tablet breakpoint. Apps can show multi-column tablet layouts. Turning this off restores the phone layout (larger text and less information). Changes take effect next time you launch an app.
This is the physical panel orientation currently used by the runtime; it is managed by the orientation policy. You control it directly only when a forced orientation is selected.
Native emulator windows offer the most reliable resizing, rotation and pointer alignment. They add a separate taskbar icon. Embedded mode displays Android inside ApkStart's window. Embedded mode has a built-in rotation button but may stutter or show borders during resizing or switching. Changes apply at the next launch.
